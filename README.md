# aim-trainer

Aim Trainer is a minimalist aim training game built with Bevy, designed to improve your precision and reaction speed. Shoot as many red targets as you can within 15 seconds to achieve the highest score possible. Every target you hit is worth 50 points.


# How to play 

```
git clone https://github.com/Vaaris16/aim-trainer.git
cd aim-trainer

cargo run 
```


Enjoy !
